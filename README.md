# To-Do List Web App

A responsive and user-friendly To-Do List web application developed using HTML5, CSS3 and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Add tasks using Enter key
- Responsive design
- Modern user interface
- Interactive buttons and animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
